# DreamGame

This project is a small game engine currently under development, using OpenGL and C++17. 

It has several objectives: 
- to explore 3D graphics programming using OpenGL 4.5 (Direct State Access)
- to create a psychological horror game inspired by PS1 graphics

The current name of this project, DreamGame, can have two meanings:
- to create my dream game
- to create a game where the overall atmosphere might remind players of dreams
